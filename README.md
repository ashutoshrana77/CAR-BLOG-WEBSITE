# India's 10 Most Sold Cars Till Now

A responsive, high-performance automotive editorial blog showcasing the 10 best-selling and most iconic cars in Indian automotive history.

## Features

- **Editorial Quality Imagery**: Ultra high-definition 16:9 widescreen photography for all 10 vehicles.
- **Interactive Lightbox Modal**: Click on any car image or press "View Full-Res" to inspect high-resolution details with keyboard support (ESC to exit).
- **Comprehensive Key Metrics**: Approximate cumulative sales, ex-showroom price ranges, and real-world average lifespans.
- **Deep Historical & Cultural Context**: 2–3 editorial paragraphs per vehicle highlighting why each model transformed Indian mobility.
- **Anchor Navigation & Share Links**: Direct anchor links (`#maruti-800`, `#alto`, `#swift`, etc.) with one-click copyable share links.
- **Dual Formats**:
  - Full React + Vite + Tailwind CSS application.
  - Standalone, zero-dependency HTML file (`car-blog.html` / `public/car-blog.html`) for static hosting.
- **Vercel Ready**: Pre-configured with `vercel.json` for one-click deployment.

## Tech Stack

- **Framework**: React 18 with TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Hosting**: Compatible with Vercel, Netlify, GitHub Pages, or Cloud Run

## Local Development

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```

## Deploying to Vercel

1. Push this repository to your GitHub account.
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Select your **car-blog** repository.
4. Click **"Deploy"** (Vite settings are automatically detected via `vercel.json`).
